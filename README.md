# Dimbo Tools 🚀

Plataforma de produtividade digital com ferramentas profissionais para o mercado lusófono e africano.

## Funcionalidades

- ✅ Conversor de imagens (PNG, JPEG, WEBP, BMP, GIF) com redimensionamento e qualidade ajustável
- ✅ Ferramentas PDF (Merge, Split, Compress, Protect, PDF → Imagem, PDF → Word)
- ✅ Editor de imagem avançado (filtros, crop, rotação, zoom, redimensionamento, matriz split)
- ✅ Remoção de fundo com IA (rembg)
- ✅ Gestão de utilizadores (registo, login, recuperação de password, perfil)
- ✅ Dashboard com estatísticas e histórico de conversões
- ✅ Sistema de limites diários (5 conversões/dia para plano Free)
- ✅ Interface moderna com Tailwind CSS
